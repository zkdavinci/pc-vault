
# PC Vault

Catalogo de videojuegos AAA para PC.

Proyecto del segundo parcial de Programacion Web II.

## Tecnologias
- PHP y MySQLi
- MySQL
- HTML5 y CSS3

## Funcionalidades implementadas
- Catalogo de 20 videojuegos desde MySQL.
- Busqueda por nombre y filtro por genero.
- Ordenamiento por nombre, año y rating.
- Panel de administracion con CRUD.
- Mensajes de confirmacion mediante sesiones.
- Tema claro y oscuro guardado en cookies.

## Ejecucion local
1. Copiar el proyecto en `C:\xampp\htdocs\pc-vault`.
2. Iniciar Apache y MySQL en XAMPP.
3. Crear la base de datos `pc_vault` en phpMyAdmin.
4. Importar el archivo `database/database.sql`.
5. Abrir `http://localhost/pc-vault/`.

El proyecto utiliza la opcion B del segundo parcial:
catalogo dinamico y administracion de videojuegos.
